# SupportDesk SQL API

A procedure-driven customer support backend built for learning and demonstrating Microsoft SQL Server, T-SQL, FastAPI and database-focused backend development.

## Current Stack

- Microsoft Azure SQL Database
- Microsoft SQL Server / T-SQL
- SQL Server Management Studio 22
- Python / FastAPI — upcoming
- pyodbc — upcoming

## Learning Goals

- Relational database design
- Primary and foreign keys
- Constraints
- Complex joins
- Stored procedures
- SQL functions
- Transactions
- TRY/CATCH
- Query optimization
- FastAPI integration without ORM-based persistence
